# Retail notes
The summary view omits sensitive cost/supplier fields. The low-stock view filters stock under 10; CHECK OPTION restricts edits made through that view to rows that still meet its condition. The procedure validates, locks stock, creates order/line and decrements stock in one transaction with error handling. The scalar function calculates one order's total with illustrative 18% tax; the inline TVF lists orders for a customer. Cursor processing is row-by-row and usually adds overhead; the set-based INSERT handles qualifying rows together. SQL Server views are query definitions integrated with SQL permissions/objects. MongoDB views are read-only aggregation pipelines over collections.
