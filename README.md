# Day 9 – Views, Stored Procedures, Functions and Cursors

Three SQL Server 2025 + MongoDB 8.0 assignment scenarios.

- **Set 1 – Retail Order Fulfilment:** views, CHECK OPTION, order transaction, tax functions, cursor/set-based follow-ups.
- **Set 2 – Insurance Premium Processing:** due-policy view, renewal transaction and audit, discount functions, lapsed-policy logging.
- **Set 3 – Telecom Low-Balance Follow-up:** prepaid views, transactional recharge, validity/recharge functions, low-balance alerts.

## Run
In SSMS, run `setup.sql` first in each folder, then `views.sql`, `procedures.sql`, and `cursor.sql`. The MongoDB scripts are intended for mongosh. The notes discuss cursor versus set-based approaches.

Scripts are prepared for practice but have not been executed in a local SQL Server or MongoDB instance yet.
