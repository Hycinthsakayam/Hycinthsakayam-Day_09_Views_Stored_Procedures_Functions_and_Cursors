# Telecom notes
Prepaid-only view hides postpaid subscribers; recharge summary aggregates prepaid recharge totals/counts. Recharge validates positive amount and matching plan, locks and updates balance, writes history transactionally, and returns balance through OUTPUT. ValidityDaysLeft calculates remaining days; the inline TVF returns the five latest recharges. Cursor inserts per subscriber; set-based INSERT...SELECT is generally faster as scale grows. Use STATISTICS TIME in SSMS to measure both approaches separately; timing varies by environment. MongoDB view groups unread notification records per subscriber.
